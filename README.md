# Human Protein Interaction Prediction

Machine learning models for predicting protein-protein interactions (PPIs) using sequence-based features from BioGRID data.

## Overview

This project implements a multi-phase approach to predict protein-protein interactions:

1. **Phase 1: Feature Engineering** - Extract 62 handcrafted features from protein sequences
2. **Phase 2: Baseline Modeling** - Train XGBoost and Random Forest classifiers
3. **Phase 2b: Fixed Evaluation** - Correct evaluation artifacts found in Phase 2 (symmetric features, real negative sampling, protein-disjoint splits, control baselines)

**Current best result:** XGBoost achieves **0.60 ROC-AUC** on a protein-disjoint held-out test set with real negative pairs. See [Phase 2b correction](#phase-2b-correction-important) below — the earlier 96% figure was driven by evaluation artifacts and should not be used.

## Phase 2b Correction (Important)

Phase 2's 96% ROC-AUC did not hold up under a more rigorous evaluation. Three problems were identified:

- **Negatives were synthetic.** They were generated by shuffling feature columns within the positive set, not by sampling real non-interacting protein pairs. The model could learn artifacts of the shuffling process rather than real biology.
- **Non-symmetric features.** PPIs are symmetric (A-B means the same thing as B-A), but the feature set used raw `_a`/`_b` columns. The top features being dominated by Protein A properties was a red flag for this.
- **Random (non-disjoint) train/test split.** The same protein could appear in both training and test sets, inflating performance.

Phase 2b fixes all three: features are now computed as swap-invariant `sum(a,b)` / `|a-b|` pairs, negatives are sampled as real random protein pairs excluded from the known-positive set, and the split is grouped by protein ID so no protein leaks across train/test. Two control baselines were also added to sanity-check the fix.

### Phase 2b Results

| Model | ROC-AUC | AUPRC | Precision@20 | Precision@50 | F1 | Accuracy |
|-------|---------|-------|---------------|---------------|-----|----------|
| XGBoost (fixed) | 0.5997 | 0.5803 | 0.6500 | 0.5800 | 0.5785 | 57.84% |
| Random Forest (fixed) | 0.5741 | 0.5755 | 0.7000 | 0.6200 | 0.5512 | 55.15% |

**Control baselines:**

| Control | ROC-AUC | Interpretation |
|---|---|---|
| Length-only model | 0.5605 | Close to the full model's AUC — most of the signal is coming from size/composition, not interaction-specific biology |
| Shuffled-label model | 0.5199 | Near 0.5 as expected — confirms the fixed pipeline has no remaining split/feature leakage |

**Top features (Phase 2b, symmetric):** `mw_absdiff`, `mw_sum`, `len_sum`, `inst_absdiff`, `gravy_sum`, `arom_absdiff`, `inst_sum`, `pi_sum`, `arom_sum`, `gravy_absdiff` — importance is now spread fairly evenly across sum/absdiff variants of a few properties, rather than dominated by one Protein-A-specific feature.

**Conclusion:** Hand-engineered physicochemical features alone carry weak signal for true PPI prediction once evaluation artifacts are removed. ~0.60 ROC-AUC is the realistic baseline to beat, not 0.96.

## Features

### Phase 1 Feature Engineering (62 total, raw)

**Sequence Properties:**
- Length (2 features): len_a, len_b

**Amino Acid Composition (40 features):**
- Fraction of each of 20 amino acids × 2 proteins

**Physicochemical Properties (10 features):**
- Molecular weight, aromaticity, instability index, GRAVY, isoelectric point (×2 proteins)

**Pairwise Differences (6 features):**
- diff_len, diff_mw, diff_arom, diff_inst, diff_gravy, diff_pi

**Data Quality Flags (4 features):**
- missing_seq_a, missing_seq_b, invalid_seq_a, invalid_seq_b

### Phase 2b Feature Engineering (12 total, symmetric)

For each of `len`, `mw`, `arom`, `inst`, `gravy`, `pi`: a `_sum` and `_absdiff` feature, both invariant to swapping Protein A and B.

### Top Predictive Features — Phase 2 (raw, superseded)

1. len_a (0.0499) - Protein A sequence length
2. mw_a (0.0380) - Protein A molecular weight
3. arom_a (0.0331) - Protein A aromaticity
4. comp_a_P (0.0273) - Proline composition in Protein A
5. gravy_a (0.0236) - Protein A hydropathy

*Dominance of Protein-A-specific features was one of the signals that motivated the Phase 2b correction.*

## Data

**Source:** BioGRID (Biological General Repository for Interaction Datasets)
**Link:** [BioGRID Latest Release](https://downloads.thebiogrid.org/File/BioGRID/Latest-Release/BIOGRID-ALL-LATEST.tab3.zip)

**Dataset Composition (Phase 2, superseded):**
- 1000 confirmed protein-protein interactions (positive class)
- 1000 synthetic negatives (shuffled protein pairs)
- Total: 2000 samples, balanced classes

**Dataset Composition (Phase 2b):**
- 1000 confirmed protein-protein interactions (positive class)
- ~1000 real negative pairs, randomly sampled and excluded from the known-positive set
- Protein-disjoint train/test split (grouped by protein ID, 80/20)

## Key Findings

✅ **Phase 2b evaluation is now trustworthy** - symmetric features, real negatives, protein-disjoint splits, and control baselines confirm no remaining leakage (shuffled-label AUC ≈ 0.52)

⚠️ **Realistic performance is ~0.60 ROC-AUC**, not 0.96 - the earlier figure was driven by evaluation artifacts, not real biological signal

⚠️ **Length/composition alone gets you most of the way there** - length-only control scores 0.56 AUC, close to the full model, meaning coarse size/composition features are doing most of the work

✅ **Interpretable** - feature importance clearly shows what drives predictions, and importance is now spread across features rather than dominated by one Protein-A-specific feature

## Next Steps

### Option 1: Improve negative sampling / reframe the task
- Use higher-confidence negative sets (e.g. non-interacting pairs from curated benchmarks) or pivot to evidence-quality prediction instead of interaction-vs-decoy

### Option 2: Add richer features
- Sequence similarity / alignment-based features
- Coevolution signals
- Network-degree features (with care to keep protein-disjoint evaluation)

### Option 3: Advanced Methods (Phase 3)
- ESM-2 protein language model embeddings
- Siamese neural networks
- Transformer-based models
- Should be evaluated with the same protein-disjoint, real-negative methodology established in Phase 2b - otherwise results will likely repeat the same inflation seen in Phase 2

## Limitations

1. Negative sampling is improved but still not gold-standard (absence of evidence in BioGRID isn't proof of non-interaction)
2. Small sample size (~1000 pairs)
3. Binary classification only (interaction / no interaction)
4. Validation needed on other PPI databases
5. Protein-disjoint split reduces effective train/test size compared to random splitting
